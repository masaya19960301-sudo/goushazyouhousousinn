# 配送業務管理アプリ

家具配送業者向けのトラック業務管理GASウェブアプリケーションです。
号車ごとに業務開始時・終了時の記録をスマートフォンから送信し、履歴を管理できます。

## 機能

- **業務記録の送信**
  - 業務開始/業務終了の記録
  - 号車選択（1〜10号車）
  - ドライバー名入力
  - 日時記録
  - 走行距離記録
  - 備考入力

- **履歴管理**
  - 履歴一覧表示（最新50件）
  - 号車・日付でのフィルタリング
  - 一括コピー機能

- **スマートフォン対応**
  - レスポンシブデザイン
  - ドライバー名・号車の自動保存

## セットアップ手順

### 1. Google Apps Scriptプロジェクトを作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を「配送業務管理」などに変更

### 2. ファイルを追加

1. デフォルトの `コード.gs` の内容を `Code.gs` の内容で置き換え
2. ファイル追加（＋ボタン）→「HTML」→ファイル名を「index」として追加
3. `index.html` の内容をコピー＆ペースト

### 3. スプレッドシートを設定

1. 新しいGoogleスプレッドシートを作成
2. スプレッドシートのURLからIDをコピー
   - URLの形式: `https://docs.google.com/spreadsheets/d/{SPREADSHEET_ID}/edit`
3. `Code.gs` の `SPREADSHEET_ID` を取得したIDに置き換え

```javascript
const SPREADSHEET_ID = 'あなたのスプレッドシートID';
```

### 4. ウェブアプリとしてデプロイ

1. 「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」で「ウェブアプリ」を選択
3. 以下の設定を行う：
   - 説明: 任意（例：「初回デプロイ」）
   - 次のユーザーとして実行: 「自分」
   - アクセスできるユーザー: 「全員」（または「組織内のユーザー」）
4. 「デプロイ」をクリック
5. 表示されたURLをコピー（これがアプリのURLです）

### 5. アプリを使用

デプロイ後に表示されたURLにアクセスすると、アプリが使用できます。

## 使い方

### 業務記録の送信

1. 「業務記録」タブを選択
2. 「業務開始」または「業務終了」を選択
3. 号車を選択
4. ドライバー名を入力
5. 日時を確認（自動入力されています）
6. 必要に応じて走行距離・備考を入力
7. 「送信する」ボタンをタップ

### 履歴の確認

1. 「履歴」タブを選択
2. 必要に応じてフィルター条件を設定
3. 「検索」ボタンをタップ

### 履歴のコピー

1. 履歴タブで「履歴を一括コピー」ボタンをタップ
2. クリップボードにテキスト形式でコピーされます

## カスタマイズ

### 号車の数を変更

`Code.gs` の `getTruckList()` 関数を編集してください。

### スプレッドシートの項目を追加

1. `Code.gs` の `saveRecord()` と `getHistory()` を編集
2. `index.html` のフォームを編集

## 注意事項

- 初回アクセス時にGoogleアカウントの認証が必要な場合があります
- スプレッドシートへのアクセス権限を許可してください
